# TRACE Android — مشروع مصدر أولي

هذا مشروع Android Studio مبدئي يضم أحدث ملف TRACE المتاح داخل WebView مع أذونات GPS.

## فتح المشروع
1. افتح مجلد `TRACE_Android_Studio_Project` من Android Studio.
2. استخدم JDK 17، وثبّت Android SDK Platform 35 وBuild Tools عبر SDK Manager.
3. نفّذ Sync ثم Build > Build APK(s).

## حالة النسخة الحالية — مهم
- هذا **ليس APK مبنيًا أو مختبرًا**.
- ملف واجهة TRACE مضمن في `app/src/main/assets/index.html`.
- تم إعداد صلاحيات GPS في WebView، لكن لم يتم اختبار GPS ميدانيًا.
- خرائط مصر أوفلاين بالكامل **غير متوفرة بعد**: ملف HTML الحالي يستخدم مصادر خرائط/مكتبات خارجية. يلزم توفير بيانات شوارع مصر المحلية المرخصة ودمج محرك خرائط أوفلاين (مثل MapLibre مع حزمة MBTiles/PMTiles مناسبة) ثم تغيير كود الخريطة لقراءة البيانات المحلية.
- يجب اختبار تصدير GeoJSON داخل Android WebView؛ سلوك تنزيل `blob:`/`data:` يختلف عن المتصفح وقد يتطلب ربط Android native باستخدام Storage Access Framework.
- تسجيل GPS في الخلفية أثناء قفل الشاشة غير مضمون بهذا الهيكل؛ يتطلب Foreground Service وإشعارًا دائمًا واختبارًا على الجهاز.
- لا تستخدم هذا البناء في Drive Test ميداني قبل استكمال الخرائط الأوفلاين واختبار التتبع والتصدير.

## متطلبات النسخة النهائية
1. بيانات خرائط شوارع مصر كاملة ومناسبة للاستخدام المحلي مع ترخيص يسمح بالتضمين.
2. محرك خرائط يعمل محليًا دون أي طلبات شبكة.
3. Foreground Location Service لتسجيل موثوق أثناء القيادة.
4. اختبار حفظ الجلسة لساعتين، استكمال التسجيل، وتصدير GeoJSON فعليًا.
